What the tough test caught

  • A blank “additional insured” scope could have shown as Met. Only the AI’s caution stopped it.
  • Two clauses for the same limit showed as two cards that could disagree.
  • A “recommended, not required” sentence was listed as a requirement.
  • The AI’s confidence was inconsistent between contracts.

What we fixed

  • A blank scope now always shows Needs review, however confident the AI is.
  • Clauses about the same requirement now merge into one card. The contract’s own tie-breaker rule decides which applies; with no tie-breaker, it’s Needs review.

How we checked

  • Re-ran both contracts: no unexpected changes.
  • Forced the AI to be fully confident: safety checks still held.
  • Fed in broken AI output (fake quotes, missing fields): all caught.

Limits

  • Only 2 practice contracts, written by AI, one run each.
  • No PDF reading yet; decisions aren’t saved.
  • The extra item above isn’t fixed yet.
Next step: 10–20 real contracts with advisor-written answers, 3 runs each. Measure what it catches and how much time it saves.
